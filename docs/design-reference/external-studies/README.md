# Estudos externos

Este diretório recebe apenas análises próprias e material com licença/proveniência clara.

Produtos podem ser estudados por padrões como:

- densidade e navegação por teclado;
- design tokens e primitives acessíveis;
- partitura e áudio sincronizados;
- colaboração por comentário;
- engraving e partes;
- modo de performance.

Não copiar identidade, layout completo, código, ilustrações, screenshots ou microcopy. Use `../templates/external-study-template.md`.
