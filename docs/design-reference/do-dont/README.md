# Do / Don't

## Do

- partitura como superfície principal;
- origem, destino e operação sempre nomeados;
- warnings persistentes;
- densidade editorial variada;
- componentes musicais próprios;
- estados reais e conteúdo extremo;
- diff e proveniência;
- reduced motion e teclado.

## Don't

- dashboard de métricas sem necessidade;
- card para cada bloco;
- glow/gradiente/vidro como identidade;
- ícone de brilho para toda automação;
- toast como único erro;
- copiar produto externo;
- esconder baixa confiança;
- usar texto promocional inventado em golden.
