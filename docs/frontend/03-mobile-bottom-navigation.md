# Navegação mobile

## Objetivo

Definir navegação inferior mínima para mobile sem ampliar o escopo do MVP.

## Itens permitidos

```text
Início
Transpor
Histórico
Instrumentos
Configurações
```

## Regras

- Área de toque mínima de 44x44px.
- Label acessível em todos os botões.
- Item ativo não depende apenas de cor.
- Conteúdo deve respeitar espaço inferior da navegação.

## Fora do MVP

Não incluir compartilhamento, dashboard autenticado ou painel administrativo.
