# Política de Uso Aceitável — estrutura do documento

> Status: rascunho.

## Usos proibidos

- enviar material sem autorização adequada;
- violar direitos de terceiros;
- disseminar malware ou arquivos deliberadamente hostis;
- contornar limites, créditos ou autenticação;
- compartilhar conta de forma incompatível com o plano;
- automatizar abuso, scraping ou carga não autorizada;
- tentar acessar dados de outros usuários;
- explorar vulnerabilidades sem canal autorizado;
- interferir em filas, workers, storage ou disponibilidade;
- usar o serviço para fraude, engano ou atividade ilícita;
- remover ou falsificar proveniência e marcas com finalidade enganosa;
- revender acesso sem contrato apropriado.

## Resposta a abuso

Ações possíveis, proporcionais e auditadas:

```text
aviso
limitação temporária
bloqueio de capability
suspensão
encerramento
preservação de evidências
comunicação adequada
```

## Contestação

O usuário deve possuir canal para contestar uma decisão. O sistema registra versão da política, evidências, operador e resultado.

## Pesquisa de segurança

Antes do lançamento, definir canal de divulgação responsável e regras para testes autorizados.
