# Checklist fiscal, contábil e jurídico

> Status: proposta pré-CNPJ; integração fiscal permanece desabilitada. Revisão: 2026-07-27.

## Contador

- [ ] natureza jurídica;
- [ ] CNAEs de desenvolvimento, licenciamento, manutenção e hospedagem;
- [ ] regime tributário;
- [ ] município e inscrição municipal;
- [ ] código de serviço;
- [ ] ISS e retenções;
- [ ] tributação de assinatura/créditos;
- [ ] prestação internacional;
- [ ] emissão para PF/PJ;
- [ ] cancelamento/substituição de NFS-e;
- [ ] conciliação de taxas do gateway;
- [ ] contabilização de créditos não consumidos;
- [ ] certificado e emissor.

## Jurídico/consumerista

- [ ] termos do SaaS;
- [ ] política de cancelamento;
- [ ] reembolso e arrependimento;
- [ ] SLA e limites;
- [ ] propriedade intelectual de arquivos;
- [ ] direitos autorais de partituras;
- [ ] responsabilidade do usuário;
- [ ] privacidade;
- [ ] tratamento de menores, se permitido;
- [ ] contratos institucionais.

## Evidência

Cada decisão deve possuir responsável, data, documento e prazo de revisão. Resposta verbal não deve ser convertida em regra de código sem registro.
