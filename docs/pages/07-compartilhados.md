# Página Compartilhados — fora do MVP

Esta página não deve ser implementada no MVP inicial.

## Regra

Não criar tela, rota, API ou componente de compartilhamento nesta etapa.

## Motivo

Compartilhamento exige login, permissões, propriedade, retenção específica e revisão de abuso. O MVP deve focar somente em transpor e baixar o resultado do job atual.
